# 東。西｜琵琶 × 大提琴企劃頁

這是一個可部署到 GitHub Pages 的單頁靜態網站。

## 檔案

- `index.html`：網站首頁
- `images/`：頁面使用的照片與 logo
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案

## GitHub Pages

把整個資料夾內容上傳到 GitHub repository 後，在 repository 的 Settings → Pages 中選擇：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`

儲存後等待 GitHub 產生公開網址。
